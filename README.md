# Suniye / सुनिए

An Android 11+ Hindi reading aid built for my parents. It reads shared text and selected photos/PDFs, offers camera reading, and keeps Stop, Repeat and Slow within large Hindi controls. The intended WhatsApp overlay still needs a real Redmi A4 check.

[Project, build instructions and limitations](outputs/suniye/README.md) · [Challenge evidence](outputs/suniye/docs/evidence/entry-readiness-2026-10-03.md) · [Sponsor use](outputs/suniye/docs/sponsor-tracks.md)

Source lives in `outputs/suniye/android` and `outputs/suniye/backend`; the Render blueprint keeps that directory layout. The debug APK and recorded demo are prepared as separate release assets, excluded from the source ZIP and repository snapshot. They contain synthetic material and test fixtures. This is a pilot, not a verified family deployment.

The project began during the October 2–5, 2026 challenge. Provider keys, model weights, private session histories and family messages are excluded. Code is MIT licensed; Gemma weights and Google's OCR SDK have separate terms. See [third-party notes](outputs/suniye/docs/third-party.md).
